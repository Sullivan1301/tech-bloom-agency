# Guide de Création des OG Images

## 📐 Spécifications Techniques

### Dimensions & Format

- **Taille**: 1200 x 630 pixels (ratio 1.91:1)
- **Format**: JPG ou PNG
- **Poids max**: 300 KB
- **Qualité**: 85% compression

### Emplacement

```
public/og/
├── og-home.jpg
├── og-services.jpg
├── og-portfolio.jpg
├── og-tarifs.jpg
├── og-partenariats.jpg
├── og-contact.jpg
├── og-blog.jpg
└── og-default.jpg (fallback)
```

---

## 🎨 Charte Graphique

### Éléments Obligatoires

**Background**:
- Couleur: Navy TBA (#384B70)
- Dégradé: `linear-gradient(135deg, #384B70 0%, #1A2F4B 100%)`

**Logo**:
- Position: Top-left ou center-top
- Taille: 200x80px environ
- Version: Logo blanc ou transparent

**Titre de la page**:
- Police: Bitter Bold (ou équivalent)
- Taille: 48-64px
- Couleur: Blanc (#FFFFFF)
- Position: Center ou bottom-center

**Éléments optionnels**:
- Ligne décorative rouge TBA (#B8001F)
- Icônes Lucide React blanches
- Motif géométrique discret

## 🛠️ Outils de Création

### En Ligne (Gratuits)

1. **Canva**
   - Template: "Facebook Post" (1200x630px)
   - Export: JPG qualité 85%
   - Lien: https://canva.com

2. **Figma**
   - Frame custom: 1200x630px
   - Export: JPG
   - Lien: https://figma.com

3. **Adobe Express**
   - Templates social media
   - Export optimisé
   - Lien: https://adobe.com/express

### Logiciels Pros

1. **Photoshop**
   - Nouveau document: 1200x630px
   - Export for Web: JPG 85%
   - Couleurs: RVB

2. **Affinity Photo**
   - Alternative Photoshop
   - Moins cher
   - Tout aussi puissant

## 📝 Instructions pour Designer

### Brief Créatif

**Message clé**: 
"Tech Bloom Agency est une agence digitale premium basée à Madagascar, spécialisée dans la création de sites web, le branding et le marketing digital pour PME."

**Ton**:
- Professionnel mais accessible
- Moderne et dynamique
- Axé résultats

**Éléments visuels**:
- Utiliser palette TBA (Navy, Blue, Teal, Red)
- Typographies: Bitter (titres) + Montserrat (texte)
- Espaces blancs aérés
- Hiérarchie visuelle claire

**À éviter**:
- Trop de texte (limited à 10 mots max)
- Éléments chargés
- Couleurs fluo
- Images stock génériques

## ✅ Checklist Validation

Pour chaque OG image créée :

- [ ] Dimensions 1200x630px respectées
- [ ] Format JPG avec compression 85%
- [ ] Poids < 300 KB
- [ ] Logo TBA présent et visible
- [ ] Titre de la page lisible
- [ ] Couleurs TBA respectées
- [ ] Contraste suffisant (WCAG AA)
- [ ] Fichier nommé correctement (og-[page].jpg)
- [ ] Placé dans `public/og/`
- [ ] Testé sur https://www.opengraph.xyz

## 📦 Exemple de Code d'Intégration

```tsx
// app/page.tsx
export const metadata: Metadata = {
  openGraph: {
    images: [
      {
        url: "/og/og-home.jpg",
        width: 1200,
        height: 630,
        alt: "Tech Bloom Agency - Agence Digitale Madagascar",
      },
    ],
  },
  twitter: {
    images: ["/og/og-home.jpg"],
  },
};
```
